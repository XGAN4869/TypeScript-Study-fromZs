# 手搓简易 Vue：TypeScript 练习骨架

## 这个 function 是干嘛的

这不是单独一个 function，而是一套简化版 Vue 渲染流程练习：先用 TypeScript 描述配置和虚拟节点，再通过类的继承与递归，把虚拟节点转换成真实 DOM，最后挂载到页面。

## 它接收什么数据

- Vue 初始化配置：指定挂载元素，可以是选择器字符串，也可以是真实 HTML 元素。
- 虚拟节点：包含标签名、可选文本和可选子节点。

## 它返回什么结果

- 递归渲染方法返回创建好的真实 DOM 元素。
- 初始化方法把最终 DOM 树挂载到指定元素中，没有返回值。

## 它中间做了哪几步

1. 定义 Vue 配置对象的类型。
2. 定义 Vue 类必须拥有的属性和方法。
3. 定义可以递归嵌套的虚拟节点类型。
4. 在父类中封装创建元素、填写文本和递归渲染。
5. 子类继承父类，并实现 Vue 类的类型约束。
6. 判断挂载目标是选择器还是 HTML 元素。
7. 检查目标是否存在，再把渲染结果挂载进去。

## 小白应该怎么模仿

先写类型，再写最小 DOM 能力，然后写递归渲染，最后写 Vue 初始化和挂载。每完成一小步就检查类型，不要一次把全部答案写完。

## 示例代码

下面只有手搓提示，没有答案代码。请把它作为练习清单，手动在自己的 `.ts` 文件中实现。

```ts
//    用来约束 new Vue({ ... }) 传入的配置对象。
//    el 既可以接收选择器字符串，也可以接收真实的 HTML 元素。

// 2. 定义 VueClass 接口
//    用来约束 Vue 类必须具备的实例属性和实例方法。
//    想一想：配置应该保存在哪个属性中？初始化方法应该返回什么？

// 3. 定义 Vnode 接口
//    tag：真实 DOM 的标签名，例如 div、section、header。
//    text：节点中可选的文字内容。
//    children：可选的子节点数组。
//    想一想：children 为什么要再次使用 Vnode 类型？这就是递归类型。

// 4. 定义简化虚拟 DOM 的父类 Dom

// 4.1 创建元素方法
//     接收标签名，创建并返回一个真实 DOM 元素。

// 4.2 填充文本方法
//     接收真实 DOM 元素和文本，把文本放进元素中。

// 4.3 递归渲染方法
//     第一步：根据当前虚拟节点的 tag 创建根元素。
//     第二步：判断当前节点有没有 children，并确认它是数组。
//     第三步：如果有子节点，逐个调用当前渲染方法，得到真实子元素。
//     第四步：把每个真实子元素追加到当前根元素中。
//     第五步：如果没有子节点，但存在 text，就为当前元素填充文本。
//     第六步：返回当前创建好的根元素，交给上一层递归继续追加。

// 5. 定义 Vue 子类
//    使用 extends 继承 Dom，从而复用 DOM 渲染能力。
//    使用 implements 约束 Vue 类必须符合 VueClass 接口。

// 5.1 保存 options
//     声明实例属性，并使用前面定义的 Options 类型约束它。

// 5.2 编写 constructor
//     接收 options。
//     只要子类写了 constructor，就要先调用 super()，再使用 this。
//     最后把传入的 options 保存到当前实例上。

// 5.3 编写 init 初始化方法
//     第一步：准备一棵包含多层 children 的虚拟 DOM 数据。
//     第二步：判断 options.el 是选择器字符串，还是真实 HTML 元素。
//     第三步：如果是字符串，就查询页面中的挂载元素。
//     第四步：如果没有找到挂载元素，抛出带选择器信息的明确错误。
//     第五步：调用继承来的 render，把虚拟 DOM 转成真实 DOM。
//     第六步：把渲染结果追加到挂载元素中。

// 6. 创建 Vue 实例
//    传入挂载配置，例如页面中某个元素的选择器。

// 7. 手动调用初始化方法
//    用来模拟真实 Vue 在内部自动完成初始化与挂载的过程。

// 8. 完成后自测
//    测试只有 text 的节点。
//    测试只有 children 的节点。
//    测试多层嵌套节点，观察递归是否正确。
//    测试字符串选择器和真实 HTMLElement 两种 el。
//    测试找不到挂载元素时，错误提示是否清楚。
```

## 举一反三

这类功能通常先定义输入和输出类型，再封装最小能力，接着组合能力，最后处理入口与异常。

- 通用的 DOM 操作适合放在父类中复用。
- 虚拟节点自身包含虚拟子节点，适合使用递归类型和递归函数。
- 挂载目标的类型分支应集中处理，不要散落在渲染过程中。
- 可以继续练习属性绑定、事件绑定、更新节点以及自动调用 `init`。
- `render` 每次返回当前层的根元素，是值得模仿的写法：下一层递归得到元素后，上一层才能把它接到自己的 DOM 树上。

## 一句话总结

先用接口规定数据形状，再用继承复用 DOM 能力，用递归把 Vnode 树变成真实 DOM，最后完成安全挂载。
